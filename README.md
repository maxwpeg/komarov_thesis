# Система проектирования пожарной безопасности

Веб-приложение для создания и управления проектами пожарной сигнализации с автоматической генерацией проектной документации в формате PDF.

## ✨ Последнее обновление

**Добавлена полная интеграция генерации PDF во фронтенд!**

- 🎯 Кнопка "Сгенерировать PDF" на странице проекта
- 📥 Автоматическое скачивание PDF файла
- ⏳ Визуальная индикация процесса генерации
- 🔄 Обработка ошибок с информативными сообщениями
- 📄 Имя файла: `Проект_{код}_{дата}.pdf`

См. [README_PDF_USER_GUIDE.md](README_PDF_USER_GUIDE.md) для инструкций пользователя.

## 🚀 Возможности

- ✅ **Управление проектами** - создание, редактирование, удаление проектов
- ✅ **Редактор планов этажей** - интерактивное рисование и редактирование элементов
- ✅ **Рисование стен** - инструмент двухкликового создания стен
- ✅ **Редактирование элементов** - перетаскивание, поворот, изменение размеров
- ✅ **Локальное сохранение** - изменения сохраняются локально с отложенной синхронизацией
- ✅ **Клавиатурные команды** - Shift (углы 45°), Ctrl+Z (отмена), Delete, Ctrl+S (сохранение)
- ✅ **Генерация PDF** - автоматическое создание проектной документации
- ✅ **Категоризация систем** - ЗКСПС, СПС, СОУЭ

## 📖 Использование

### Создание проекта

1. Откройте приложение в браузере
2. Нажмите "Создать проект"
3. Заполните информацию о проекте:
   - Название
   - Объект
   - Подрядчик
   - Инженер
   - Главный инженер проекта
   - Проверяющий
4. Нажмите "Создать"

### Редактирование плана этажа

1. Выберите проект из списка
2. Выберите этаж или создайте новый
3. Загрузите фоновое изображение плана
4. Используйте инструменты для добавления элементов:
   - **Стены** - двухкликовое рисование
   - **Двери/Окна** - перетаскивание из панели
   - **Пожарные извещатели** - размещение на плане

### Клавиатурные команды

- **Shift** - при рисовании стен ограничивает углы 45°
- **Ctrl+Z** - отмена последнего действия
- **Delete** - удаление выбранного элемента
- **Ctrl+S** - сохранение изменений

### Генерация PDF

1. Откройте проект
2. Нажмите "Сгенерировать PDF"
3. PDF создается автоматически со следующими страницами:
   - Титульные листы (с подписями и без)
   - Общая информация (A3, A4)
   - Чертежи ЗКСПС (каждый на A3 горизонтальном)
   - Чертежи СПС (каждый на A3 горизонтальном)
   - Чертежи СОУЭ (каждый на A3 горизонтальном)
   - Схемы подключения
   - Спецификация
   - Расчет токопотребления

## 📚 API Документация

### Проекты

- `GET /api/projects` - получить все проекты
- `GET /api/projects/{id}` - получить проект по ID
- `POST /api/projects` - создать проект
- `PATCH /api/projects/{id}` - обновить проект
- `DELETE /api/projects/{id}` - удалить проект
- `POST /api/projects/{id}/generate-pdf` - сгенерировать PDF

### Планы этажей

- `GET /api/floor-plans/{id}` - получить план этажа
- `POST /api/projects/{id}/floor-plans` - создать план этажа
- `PATCH /api/floor-plans/{id}` - обновить план
- `DELETE /api/floor-plans/{id}` - удалить план
- `POST /api/floor-plans/{id}/batch-save` - пакетное сохранение элементов

### Элементы

- `POST /api/walls` - создать стену
- `PATCH /api/walls/{id}` - обновить стену
- `DELETE /api/walls/{id}` - удалить стену
- `PATCH /api/{element_type}/{id}` - обновить элемент (doors, windows, fire_alarms)

## 🎨 Структура PDF

Подробное описание структуры генерируемого PDF см. в [PDF_GENERATION_GUIDE.md](PDF_GENERATION_GUIDE.md).

### Основные разделы:

1. **Титульные листы** - информация о проекте и подписи
2. **Общая информация** - описательные страницы
3. **Чертежи по системам** - планы этажей с категоризацией
4. **Схемы подключения** - диаграммы соединений
5. **Спецификация** - перечень оборудования
6. **Расчеты** - токопотребление и другие расчеты

## 🔧 Настройка

### Константы ([consts.py](consts.py))

- `PAGESIZE_A4` - размер A4 (210×297 мм)
- `PAGESIZE_A3_LANDSCAPE` - размер A3 горизонтальный (420×297 мм)
- `DEFAULT_BORDERS` - отступы рамок (левый 20мм, остальные 5мм)
- `DEFAULT_FONT_NAME` - шрифт GOST Type A
- `DEFAULT_FONT_SIZE` - 12pt

### Учетные данные по умолчанию

Можно изменить в `DEFAULT_CREDS_DICT` в [consts.py](consts.py):
- Подрядчик
- Инженер
- ГИП
- Проверяющий
