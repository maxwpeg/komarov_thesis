# Frontend

React-приложение для работы с проектами пожарной сигнализации и СОУЭ. Запускается из корня папки `frontend/`.

## Структура

- `src/` - исходный код приложения.
- `public/` - статические файлы.
- `scripts/` - служебные скрипты запуска тестов.
- `package.json` и `package-lock.json` - зависимости и npm-команды.

## Локальный запуск

```powershell
cd frontend
npm install
npm start
```

Приложение открывается на `http://127.0.0.1:3000`.

Для локальной разработки запросы `/api/...` проксируются на backend через `proxy` в `package.json`. Если backend доступен по другому адресу, создайте `.env` в этой папке:

```env
REACT_APP_API_BASE_URL=http://127.0.0.1:8000
```

После изменения `.env` перезапустите frontend.

## Роли И Разделы

Роль `developer` является текущим эквивалентом администратора. Для нее доступны пользователи, аудит, дообучение, корзина проектов и служебные операции.

В интерфейсе добавлены:

- страница аудита с фильтрами и экспортом CSV/JSON;
- прогресс фоновых задач и retry для failed-задач;
- фильтры списка проектов по автору, статусу, объекту, номеру и датам;
- список версий PDF в карточке проекта;
- отображение типа, размера и состояния загружаемого файла.

## Ограничения Загрузки

Планы этажей в текущей версии загружаются как изображения с минимальным разрешением `200x200` пикселей. PDF-планы не импортируются как планы этажей; PDF используется как артефакт проекта или документ оборудования в поддержанных сценариях.

## Проверки

```powershell
npm.cmd test -- --watch=false --runInBand
npm.cmd run build
```

Backend запускается отдельно:

```powershell
cd ..\backend
uvicorn backend.app:app --host 127.0.0.1 --port 8000
```
