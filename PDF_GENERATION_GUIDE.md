# Руководство по генерации PDF

## Обзор

Класс `Project` теперь поддерживает комплексную генерацию PDF-документов с автоматической структурой страниц согласно требованиям проектной документации.

## Структура генерируемого PDF

При вызове метода `launch()` создается PDF со следующими страницами:

1. **Титульный лист** (без подписи)
2. **Титульный лист** (с подписями руководителей)
3. **Страница A3 горизонтальная** - общая информация
4. **Страница A4 вертикальная** - дополнительная информация
5. **Страница A4 вертикальная** (рамка типа 2) - специальная страница
6. **2 страницы A4 вертикальных** - резервные страницы
7. **Чертежи ЗКСПС** - каждый на отдельной странице A3 горизонтальной
8. **Чертежи СПС** - каждый на отдельной странице A3 горизонтальной
9. **Чертежи СОУЭ** - каждый на отдельной странице A3 горизонтальной
10. **Схемы подключения** - страница A3 горизонтальная
11. **Спецификация** - страница A3 горизонтальная
12. **Расчет токопотребления** - страница A4 вертикальная

## Использование

### Базовое использование

```python
from Project import Project
from consts import DEFAULT_CREDS_DICT

# Подготовка учетных данных
creds = {
    "Contractor": "ООО \"Флагман-СБ\"",
    "Engineer": "Комарова Н.С.",
    "CPE": "Гостев В.В.",
    "Checker": "Комаров С.Л.",
    "Facility": "Магазин ИП Гришанов А.В.",
    "Facility Address": "Тульская обл., г. Ефремов, ул. Энтузиастов, д. 17",
    "Project Description": "Система пожарной сигнализации",
    "Stage": "«Р»"
}

# Создание проекта
project = Project(
    project_type="ПС",
    number=1,
    year=2024,
    creds=creds,
    number_of_floors=2,
    floor_plans_data=[]  # Список планов этажей
)

# Генерация PDF
project.launch()
project.save()
```

## Категоризация планов этажей

Система автоматически категоризирует планы этажей по типам систем на основе их названий:

- **ЗКСПС** - планы, содержащие в названии "ЗКСПС", "ЗАКРЫТИЕ", "ЗАДВИЖК"
- **СОУЭ** - планы, содержащие "СОУЭ", "ОПОВЕЩ", "ЭВАКУАЦ"
- **СПС** - все остальные планы (по умолчанию)

## Добавление чертежей

Метод `add_drawing_page_with_image()` позволяет добавить страницу с чертежом:

```python
project.add_drawing_page_with_image(
    image_path="path/to/image.png",
    pagesize=PAGESIZE_A3_LANDSCAPE,
    title="Название чертежа"
)
```

Чертеж будет автоматически:
- Преобразован в градации серого
- Масштабирован для вписывания в рамку
- Отцентрирован относительно области рисования

## Методы класса Project

### `__init__()`
Инициализация проекта с параметрами.

**Параметры:**
- `project_type` (str): Тип проекта (по умолчанию "ПС")
- `number` (int): Номер проекта
- `year` (int): Год создания
- `creds` (dict): Словарь учетных данных
- `number_of_floors` (int): Количество этажей
- `floor_plans_data` (list): Список данных планов этажей

### `add_page(pagesize, mtbox_type)`
Добавляет стандартную страницу с рамкой.

**Параметры:**
- `pagesize` (tuple): Размер страницы (PAGESIZE_A4, PAGESIZE_A3_LANDSCAPE и т.д.)
- `mtbox_type` (str): Тип штампа ("1" или "2")

### `add_title_page(signed)`
Добавляет титульный лист.

**Параметры:**
- `signed` (bool): С подписями или без

### `add_drawing_page_with_image(image_path, pagesize, title)`
Добавляет страницу с чертежом.

**Параметры:**
- `image_path` (str): Путь к изображению чертежа
- `pagesize` (tuple): Размер страницы
- `title` (str): Заголовок чертежа

### `categorize_floor_plans()`
Категоризирует планы этажей по системам.

**Возвращает:**
- Кортеж из трех списков: (zkspс_plans, sps_plans, soue_plans)

### `launch()`
Генерирует полный PDF-документ со всеми страницами.

### `save()`
Сохраняет PDF-файл на диск.

## API Endpoint

**POST** `/api/projects/{project_id}/generate-pdf`

Генерирует PDF для указанного проекта.

**Параметры:**
- `project_id` (int): ID проекта

**Ответ:**
- PDF файл для скачивания

**Пример запроса:**
```bash
curl -X POST http://localhost:8000/api/projects/1/generate-pdf -o project.pdf
```

## Настройка и константы

Все константы определены в [consts.py](consts.py):

- `PAGESIZE_A4` - размер A4 вертикальный
- `PAGESIZE_A3_LANDSCAPE` - размер A3 горизонтальный
- `DEFAULT_BORDERS` - отступы рамки (левый 20мм, остальные 5мм)
- `MAIN_TITLE_BOX_DICT` - размеры штампов
- `DEFAULT_FONT_NAME` - шрифт GOST Type A
- `DEFAULT_FONT_SIZE` - размер шрифта 12pt

## Примечания

1. **Изображения чертежей** автоматически конвертируются в градации серого для лучшей печати
2. **Нумерация страниц** ведется автоматически и отображается в штампе
3. **Код проекта** формируется автоматически в формате "РП-ЗК-{номер}/{год}-{тип}"
4. **Имя файла** формируется из названия объекта, номера и подрядчика
