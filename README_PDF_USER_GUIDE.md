# Генерация PDF - Инструкция для пользователя

## Как сгенерировать PDF проекта

1. **Откройте проект**
   - Перейдите на страницу списка проектов
   - Нажмите на карточку нужного проекта

2. **Нажмите кнопку "Сгенерировать PDF"**
   - Кнопка находится в правом верхнем углу страницы деталей проекта
   - Во время генерации кнопка будет неактивна и покажет текст "Генерация PDF..."

3. **Дождитесь завершения**
   - Процесс генерации может занять несколько секунд
   - PDF автоматически скачается в папку загрузок вашего браузера

4. **Проверьте PDF**
   - Имя файла: `Проект_РП-ЗК-XXX/YY-ПС_2026-01-26.pdf`
   - Файл содержит все разделы проектной документации

## Структура создаваемого PDF

### Титульные листы
- Титульный лист без подписей
- Титульный лист с подписями руководителей

### Информационные страницы
- Страница A3 горизонтальная (общая информация)
- Страница A4 вертикальная (дополнительная информация)
- Страница A4 вертикальная с рамкой типа 2
- 2 резервные страницы A4

### Чертежи планов этажей
Планы автоматически категоризируются по системам:

- **ЗКСПС** (закрытие клапанов противодымной защиты и систем)
  - Если название плана содержит: "ЗКСПС", "ЗАКРЫТИЕ", "ЗАДВИЖК"
  - Каждый чертеж на отдельной странице A3 горизонтальной
  
- **СПС** (система пожарной сигнализации)
  - Все планы по умолчанию относятся к СПС
  - Каждый чертеж на отдельной странице A3 горизонтальной
  
- **СОУЭ** (система оповещения и управления эвакуацией)
  - Если название плана содержит: "СОУЭ", "ОПОВЕЩ", "ЭВАКУАЦ"
  - Каждый чертеж на отдельной странице A3 горизонтальной

### Технические разделы
- Схемы подключения (A3 горизонтальная) - в разработке
- Спецификация оборудования (A3 горизонтальная) - в разработке
- Расчет токопотребления (A4 вертикальная) - в разработке

## Особенности

### Автоматическое форматирование
- Все чертежи конвертируются в градации серого
- Изображения масштабируются и центрируются в рамке
- Автоматическая нумерация страниц
- Штамп с кодом проекта на каждой странице

### Категоризация планов
Чтобы план попал в нужную категорию, добавьте ключевое слово в название:

```
✅ Правильно:
- "План 1 этажа - ЗКСПС"
- "2 этаж СОУЭ"
- "Подвал СПС"
- "1 этаж - Система оповещения"

❌ Неправильно (все попадут в СПС):
- "План 1"
- "Этаж 2"
- "Подвал"
```

### Проверка перед генерацией
Убедитесь, что:
- ✅ Загружены все необходимые планы этажей
- ✅ Планы имеют правильные названия с указанием системы
- ✅ Заполнены все поля проекта (объект, подрядчик, инженер и т.д.)
- ✅ Изображения планов доступны в папке uploads/

## Устранение проблем

### PDF не скачивается
**Проблема:** Кнопка нажата, но файл не появляется  
**Решение:**
1. Проверьте консоль браузера (F12 → Console) на наличие ошибок
2. Убедитесь, что backend запущен (http://localhost:8000)
3. Проверьте, что у проекта есть хотя бы один план этажа

### Ошибка "Проект не найден"
**Проблема:** Сервер возвращает 404  
**Решение:**
1. Убедитесь, что проект существует в базе данных
2. Проверьте правильность ID проекта в URL

### Ошибка "No floor plans found"
**Проблема:** В проекте нет планов этажей  
**Решение:**
1. Загрузите хотя бы один план этажа
2. Дождитесь завершения обработки плана
3. Попробуйте сгенерировать PDF снова

### Пустой PDF или неполная структура
**Проблема:** PDF создается, но в нем мало страниц  
**Решение:**
1. Проверьте, что изображения планов существуют в папке uploads/
2. Убедитесь, что поле original_image_path заполнено корректно
3. Проверьте права доступа к папке uploads/

### Чертежи не отображаются
**Проблема:** Страницы есть, но изображений нет  
**Решение:**
1. Убедитесь, что файлы изображений существуют
2. Проверьте формат изображений (должны быть PNG, JPG)
3. Проверьте, что путь к файлу правильный (относительно корня проекта)

## Технические детали

### API Endpoint
```
POST /api/projects/{project_id}/generate-pdf
```

**Ответ:**
- `Content-Type: application/pdf`
- `Content-Disposition: attachment; filename="..."`
- Binary PDF data

### Время генерации
- Проект без планов: ~1-2 секунды
- Проект с 5 планами: ~3-5 секунд
- Проект с 10+ планами: ~5-10 секунд

### Требования
- Backend должен быть запущен
- Установлены все зависимости из requirements.txt
- Папка outputs/ должна существовать и быть доступной для записи

## Советы по оптимизации

### Размер файлов
- Используйте изображения планов в разумном разрешении (не более 3000×3000 px)
- Сжимайте изображения перед загрузкой
- PDF автоматически конвертирует в градации серого для уменьшения размера

### Качество чертежей
- Загружайте четкие, контрастные изображения
- Избегайте размытых или низкокачественных сканов
- Оптимальное разрешение: 150-300 DPI

### Производительность
- Не генерируйте PDF слишком часто (используйте кэширование)
- Генерация происходит на сервере, фронтенд только ждет
- При большом количестве планов процесс может занять больше времени

## Горячие клавиши

Нет специальных горячих клавиш для генерации PDF. Используйте кнопку в интерфейсе.
